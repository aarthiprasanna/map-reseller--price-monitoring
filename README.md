MAP Reseller Price Monitoring

Project Overview

This project focuses on monitoring reseller product prices against Minimum Advertised Price (MAP) policies.

Problem Statement

Products advertised below the permitted price may violate MAP policies. The goal is to identify potential price violations and support pricing compliance monitoring.

Objectives

Prepare and validate product pricing data.

Process reseller and product information.

Compare advertised prices against defined price thresholds.

Identify potential MAP violations.

Technologies

Python

SQL

Pandas

BeautifulSoup (for web scraping, if used in the project)

Workflow

1.Collect product pricing information.

2.Clean and validate the data.

3.Process product and reseller details.

4.Compare advertised prices with applicable price thresholds.

5.Identify and review potential violations.

Project Status

Project documentation in progress.

Data Privacy
